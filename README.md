# Limited Lab

A Magic: The Gathering Limited trainer (draft, sealed, deck building and play against bots), graded from real 17lands data.

**Open it:** https://stevyv.github.io/limited-lab/

On iPhone: open the link in Safari, then Share → Add to Home Screen for a full-screen app that also works offline.

This repository holds only the built site. Card images are loaded from Scryfall; card data © Wizards of the Coast. Unofficial fan content, not affiliated with Wizards of the Coast.
